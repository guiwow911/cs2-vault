# CS2 Vault — 模拟开箱

> 🎁 基于真实 CS2 皮肤数据的模拟开箱网站，纯静态前端，零依赖。

## 🌐 在线访问
**[https://guiwow911.github.io/cs2-vault/](https://guiwow911.github.io/cs2-vault/)**

## ✨ 功能
- 🎁 全部真实 CS2 武器箱 / 纪念品包 / 胶囊，含完整箱内物品列表
- 🎰 滚轮开箱动画 + 官方稀有度概率（缺失档位自动归一化，贴纸胶囊等概率）
- ×1 / ×3 / ×5 / ×10 / ×50 / ×100 批量开箱，100 连开带稀有度统计与盈亏汇总
- 🔫 皮肤库：全量浏览，稀有度筛选，无限滚动
- 🎒 背包系统：保存开出物品，逐个卖或按筛选一键卖出
- 📜 开箱历史记录
- 💰 余额系统（localStorage 持久化，余额不足时会提示还差多少钱）
- 🖼️ 图片全部来自 Steam 官方 CDN

## 🛠 技术
纯 HTML / CSS / JS · [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API) · GitHub Pages
